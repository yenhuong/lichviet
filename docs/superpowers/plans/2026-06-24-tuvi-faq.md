# Plan: Thêm Slide Câu Hỏi Tử Vi Và Màn Hình Chi Tiết

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Triển khai thêm một thẻ câu hỏi tử vi thường gặp đồng cấp dưới dạng Slider trượt ngang luân phiên sau 4 giây ở vị trí đếm ngược sự kiện tại Trang chủ, và tạo màn hình chi tiết hiển thị câu hỏi, câu trả lời, cùng nút CTA dẫn đến tính năng tử vi nghề nghiệp.

**Architecture:** Bố cục Slider sử dụng một khung chứa viewport `relative overflow-hidden` và một track trượt `flex w-[200%] transition-transform`. Sử dụng hiệu ứng chuyển đổi class qua Javascript `setInterval` để cập nhật vị trí trượt và kích thước/màu sắc của các dấu chấm chỉ báo. Màn hình chi tiết là một trang tĩnh mới kế thừa thiết kế mockup di động của dự án.

**Tech Stack:** HTML5, Tailwind CSS, Vanilla Javascript.

### Task 2: Triển khai Logic trượt tự động và Cập nhật chỉ báo trên Trang chủ

**Files:**
- Modify: `prototype/TrangChu_V2.html`

- [ ] **Step 1: Viết script điều khiển Slider tự động chuyển trang**
  Thêm đoạn code Javascript vào cuối khối `<script>` ở cuối file `TrangChu_V2.html` (trước thẻ đóng `</body>`).

  *Mã nguồn thêm vào:*
  ```javascript
  // Logic: Chạy Slider tự động chuyển đổi giữa Sự kiện và Hỏi đáp Tử vi
  (function () {
      let activeIndex = 0;
      const track = document.getElementById("carouselTrack");
      const dot0 = document.getElementById("carouselDot0");
      const dot1 = document.getElementById("carouselDot1");

      if (track && dot0 && dot1) {
          setInterval(function () {
              activeIndex = (activeIndex === 0) ? 1 : 0;
              
              if (activeIndex === 0) {
                  track.style.transform = "translateX(0%)";
                  // Chấm 0 mở rộng màu đỏ, Chấm 1 thu nhỏ xám
                  dot0.className = "w-4 h-1 bg-[#C62828] rounded-full transition-all duration-300";
                  dot1.className = "w-1.5 h-1 bg-gray-300 rounded-full transition-all duration-300";
              } else {
                  track.style.transform = "translateX(-50%)";
                  // Chấm 1 mở rộng màu tím, Chấm 0 thu nhỏ xám
                  dot0.className = "w-1.5 h-1 bg-gray-300 rounded-full transition-all duration-300";
                  dot1.className = "w-4 h-1 bg-[#6B21A8] rounded-full transition-all duration-300";
              }
          }, 4000); // 4 giây chuyển đổi luân phiên
      }
  })();
  ```
